About DREAM

Simple syntax. Powerful ideas.

DREAM is a custom programming language created by OpenQ. It is designed to be challenging while providing its own unique syntax for variables, input, math, loops, pixels, keyboard controls, and more.

Features

Some of the things you can do with DREAM.

Variables

Store information using DREAM's simple variable syntax.

Math

Perform calculations directly inside DREAM programs.

Loops

Repeat code using normal and infinite repeat loops.

User Input

Let your programs communicate with the user.

Pixels

Draw and clear pixels to create graphical programs.

Keyboard Events

Detect keyboard input for interactive programs and games.

Examples

A few examples of DREAM code.

Game 

s playerX = 10
s playerY = 10

s foodX = rdm [1,30]
s foodY = rdm [1,20]

pxl[playerX,playerY]
pxl[foodX,foodY]

rpt[frvr]

    w [w] clk
        s playerY = playerY - 1
    end

    w [s] clk
        s playerY = playerY + 1
    end

    w [a] clk
        s playerX = playerX - 1
    end

    w [d] clk
        s playerX = playerX + 1
    end

    clrr[playerX,playerY]
    pxl[playerX,playerY]

    if playerX == foodX
        if playerY == foodY

            clrr[foodX,foodY]

            s foodX = rdm [1,30]
            s foodY = rdm [1,20]

            pxl[foodX,foodY]

        end
    end

end
Input & Conditions 

r [What is your name?]

r #usrinp

s age = 15

r [Hello, {usrinp}!]

r [You are {age} years old.]

if age >= 13
    r [You are a teenager.]
else
    r [You are not a teenager.]
end
